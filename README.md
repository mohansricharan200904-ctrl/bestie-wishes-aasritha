# A Little Birthday Surprise 🎁

A mobile-friendly birthday wishes website made with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content
- `styles.css` — colors, layout, responsive styles, and animations
- `script.js` — countdown, interactive gifts, music, confetti, and personalization

Keep all three files in the same folder.

## Run it
1. Download and extract the ZIP.
2. Open `index.html` in Chrome, Edge, Firefox, or Safari.
3. Tap **Open your surprise** or the gift box.
4. Use the music button to play/pause the original synthesized tune. Browsers require a tap before audio can start.

No build tools or package installation are required. Google Fonts are optional; an internet connection is needed for those fonts. The site otherwise works locally.

## Personalize it before sharing
Open `script.js` in a text editor and edit the `birthdayConfig` values at the top:

```js
const birthdayConfig = {
  name: "Bestie",
  date: "2026-10-17",
  homeMessage: "Life is a little brighter, louder, and a whole lot better with you in it.",
  finalMessage: "May your smile stay bright, your heart stay kind, and this year surprise you in the best possible ways.",
  signature: "Your bestie ♡"
};
```

Use the date format `YYYY-MM-DD`. The website's settings panel can also change the name, date, homepage message, and signature in the current browser. Those quick changes are saved locally in that browser only; they do not travel with a link. For a shareable personalized version, edit `script.js` first.

To edit the letter, find the `<div class="letter-body" id="letterBody">` section in `index.html`.

## Share it with your friend
**Option A — share the files:** ZIP the folder and send it through WhatsApp, email, or Drive. Ask the recipient to extract it and open `index.html`.

**Option B — share a website link:** Upload the three files to a static hosting service such as GitHub Pages, Netlify, or Cloudflare Pages. Follow that service's current instructions, then share the published URL. Keep `index.html`, `styles.css`, and `script.js` together in the published folder.

## Notes
- The countdown targets midnight at the start of the birthday date in the visitor's local timezone.
- Music is generated by the browser using the Web Audio API; there is no bundled song or copyrighted track.
- The page does not send personal information to a server. The settings panel uses local browser storage on the device where it is edited.
- For privacy, only use photos or personal details you have permission to share.
